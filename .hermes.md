# Project: syncwave

Tags: syncwave, media, services

## What it is
Our working fork of **Syncwave** (`github.com/TeddOravec/syncwave`, branch `tandy`) — a self-hosted
collaborative listening room, built as the replacement for Hangout.fm after it shut down. Rooms sync
every listener to the same second of the same track; audio is resolved **server-side** (yt-dlp +
ffmpeg + Deno), so every client gets the identical stream. No accounts for listeners — the room link
is the credential; one instance-wide `/admin` password.

Placement and access model: `02_Infrastructure/Services/Syncwave.md` in the vault. Short version:
CT 1490 on Sol, container `syncwave` on `:3000`, `https://listen.tandy.land` behind Authentik
forward-auth (group `Syncwave Users`), two front doors (ExoCaddy CT 250 for the public/work path,
home Caddy CT 199 for home + mesh). Permanent room: `/r/WORK`.

## Where it stands
- **Live** = `/opt/syncwave` on the CT, checked out on branch `tandy`, currently `2d51b50`.
  Promote = `git fetch fork && git merge --ff-only fork/tandy && docker compose up -d --build`.
- **Dev** = container `syncwave-dev` on `:3100`, built from `/opt/syncwave-dev/src` (same repo) with
  its own `data/` + `cache/`. No auto-pull timer yet — `git pull` it by hand. Its `data/rooms.json`
  is a copy of live's, so it tests against the real play history.
- Working copy here; edit → commit → push → pull+rebuild dev → verify → promote.

## Conventions
- Every change is its own commit with the reasoning in the message, listed in `PATCHES.md` with its
  symptom and whether it is upstream-PR shaped. `upstream`/`origin` (SAKMZ) stays pristine.
- Never patch a deployed container in place. Never rsync the source over `/opt/syncwave`.
- Backup `data/` (`/opt/backups/syncwave-<ts>/` on the CT) before any destructive step; PBS covers
  the guest nightly at 21:00.

## Lessons that cost a session
- **The AI DJ's suggestions are only as good as the history you put in the prompt.** Persona `taste`
  + current track at temperature 0 = the same five names forever. A prompt that *mentions* history is
  not enough — history has to lead, the persona has to be named a tiebreaker, and a quota has to make
  ignoring it visible. `lib/taste.mjs` derives the profile; `djUseHistory` switches it off.
- **LLM picks are search queries, not tracks.** They go through normal search and a miss costs a row,
  not the queue. Expect noisy resolutions (`Mark Ronson - <someone else's song>`) — filtered by search,
  not by the prompt.
- A room's `history` is capped at 120 per room and persisted; `current`/`isPlaying` are NOT persisted,
  so after a restart a room has its queue but no current track.
- `yt-dlp` is not on `PATH` in the container: `/app/node_modules/youtube-dl-exec/bin/yt-dlp`.
- iOS ignores `volume` programmatically (only `muted`), and ignores an SVG apple-touch-icon.
